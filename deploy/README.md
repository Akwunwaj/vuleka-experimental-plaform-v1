# Oracle Cloud deployment

This runs the Express app, queue worker, MariaDB, and Nginx on one Oracle Cloud VM using Docker Compose.

## VM setup

Create an Ubuntu Always Free VM. Allow TCP ports 80 and 443 in the Oracle security list and run:

```bash
sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
sudo apt-get update
sudo apt-get install -y docker.io docker-compose-plugin git
sudo usermod -aG docker "$USER"
```

Log out and back in after adding the user to the Docker group.

## Deploy

```bash
git clone https://github.com/Akwunwaj/vuleka-experimental-plaform-v1.git app
cd app
cp .env.example .env.production
nano .env.production
mkdir -p deploy/certbot/www deploy/certbot/conf
docker compose --env-file .env.production -f docker-compose.production.yml up -d --build
```

Set `APP_URL` to the public HTTPS URL and strong values for `SESSION_SECRET`, `CREDENTIAL_ENCRYPTION_KEY`, `DB_PASSWORD`, and `DB_ROOT_PASSWORD`. Never commit `.env.production`.

## HTTPS

Point DNS at the VM, replace `server_name _;` with the domain, then obtain a certificate:

```bash
docker compose -f docker-compose.production.yml stop nginx
sudo apt-get install -y certbot
sudo certbot certonly --standalone -d app.example.com
docker compose --env-file .env.production -f docker-compose.production.yml start nginx
```

Add the TLS server block generated by Certbot to `deploy/nginx.conf`. Renew with `sudo certbot renew` and restart Nginx after renewal.

## Operations

```bash
docker compose --env-file .env.production -f docker-compose.production.yml ps
docker compose --env-file .env.production -f docker-compose.production.yml logs -f app worker
docker compose --env-file .env.production -f docker-compose.production.yml exec app npm run db:verify
```

The MariaDB volume persists across rebuilds. Back it up before upgrades; do not remove `mariadb_data` unless intentionally destroying the database.
